GBA一代。继承大部分正文汉化，补全本轮已定位的标题和菜单图形。**不冒称全游戏100%汉化、全通关或跨版存档认证。**

## 使用

包内不含ROM、BIOS或存档，必须使用自己合法持有的原版日版8MiB GBA ROM。源SHA见校验文件。

```sh
python -I apply_bps.py "自己的原版.gba" genki-slime-cn-v22.bps "新的v22.gba"
```

脚本拒绝错源、损坏补丁和覆盖已有输出；也可用Flips应用BPS。此补丁从**原版**应用，不是从v20再次打。不要把NDS二代或SFC游戏作为输入。

请使用支持GBA的模拟器。先备份自己的电池存档；不加载旧版本即时存档。现有日版/跨版电池存档兼容未认证，测试建议从新游戏开始。
